# MAX FUGLESPRENGER

Canonical production source for **max.iverfinne.no**.

- `index.html` is the complete self-contained iPhone-first PWA/game.
- Target device: iPhone 16e from the Home Screen.
- No persistent text HUD.
- Roguelite boons are icon-only and docked at the bottom above the Home indicator.
- A new run starts without planted crops; seeds are collected in-world, planted, watered and defended from floating garden creatures.
- Vercel project link: `.vercel/project.json`.
- Production domain: `max.iverfinne.no`.

The old copy inside `tv.iverfinne.no` is retained only as an emergency fallback while the production hostname is transitioned fully to the dedicated Vercel project.
