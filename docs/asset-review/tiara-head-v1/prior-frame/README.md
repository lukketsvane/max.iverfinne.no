# Initial native frame capture

These unchanged files record the actual first Figma frame master and its
666-MATCH source audit, before the canonical master became a component so the
animation sets could share its pixels. They are historical evidence.

The copied receipt preserves its original path strings and hashes. Those
strings describe the original capture locations; the matching historical
files now sit beside this README. The current receipt and source proof live in
the parent review directory and `assets/tiara-head-v1/figma-vector.json`.
